# HireLoom — Weave Your Career Path

HireLoom is a full-stack job and internship tracking platform that helps users manage applications, deadlines, and recruitment progress.

## Features
- User authentication
- Track internship/job applications
- Application status management (Applied, OA, Interview, Offer, Rejected)
- Dashboard for tracking progress
- Search and filtering
- Responsive frontend UI

## Tech Stack

### Backend
- Java
- Spring Boot
- Spring Security
- JWT Authentication
- PostgreSQL
- JPA / Hibernate

### Frontend
- React
- Tailwind CSS
- Axios
